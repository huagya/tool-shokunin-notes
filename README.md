# tool-shokunin-notes

ツール職人（万能開発パートナー）とモグ モグのあいだで決めた**開発方針・説明書**の正本リポジトリ。

## ファイル

| ファイル | 内容 |
|----------|------|
| `ツール職人-説明書.md` | 役割・記憶・裁量・作業フロー・トークン方針など |

## 使い方

- 迷ったらまず `ツール職人-説明書.md` を見る
- 方針が変わったらこのリポを更新する（チャットだけの口約束にしない）
- 個別ツールのコードは別リポ（`tool-scaffold` など）。ここはメモ専用

## クローン例

```bat
cd /d F:\_AI_tool
git clone https://github.com/huagya/tool-shokunin-notes.git
```
